## 1. 测试环境准备

### 1.1 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | macOS 12+ 或 Windows 10 1809+ |
| Node.js | v22.x 或更高 |
| pnpm | 9.x 或更高 |
| Rust | 1.80+ |

### 1.2 启动应用

```bash
cd /path/to/DiskMind/app
pnpm install
pnpm tauri:dev
```

等待控制台出现 `Listening on http://localhost:1420`，Tauri 桌面窗口弹出即可开始测试。

### 1.3 测试数据准备

为了充分测试各项功能，建议准备以下测试目录：

**目录 A — 常规文件结构**（用于 Explorer 测试）：
- 一个包含多层嵌套子目录的文件夹（建议 3-5 层）
- 混合包含不同类型文件（`.txt`、`.png`、`.pdf`、`.zip` 等）
- 包含隐藏文件（如 `.gitignore`、`.DS_Store`）

**目录 B — 重复文件测试**（用于重复检测）：

```bash
mkdir -p /tmp/diskmind-test
cd /tmp/diskmind-test
dd if=/dev/urandom of=base.bin bs=1M count=8 2>/dev/null
cp base.bin copy1.bin
cp base.bin copy2.bin
dd if=/dev/urandom of=other.bin bs=1M count=5 2>/dev/null
cp other.bin other-copy.bin
dd if=/dev/urandom of=unique.bin bs=1M count=3 2>/dev/null
```

预期产物：6 个文件，2 组重复（8MB × 3 + 5MB × 2），1 个独立文件。
